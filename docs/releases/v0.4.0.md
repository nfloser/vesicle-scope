# VesicleScope 0.4.0

VesicleScope 0.4.0 releases the evidence-aware research workspace on the
verified BioFVM continuum path. It is **not biologically validated** as a
predictive EV model.

## New since 0.3.0

- Longitudinal measurement views retain specimen preparation, centrifugation,
  assay, marker/cargo and limitation metadata.
- Perturbation and EV-phenotype views keep evidence, sources and explicit unknown
  effects separate from executable model inputs.
- Users explicitly map study phenotypes to study-declared transport experiments
  before executing independent population runs through the canonical server-side
  BioFVM workflow.
- Measurement/model overlays require an explicit observation mapping and equal
  stored time and unit semantics. Missing times and incompatible units remain
  visible without interpolation or residual calculation.
- Spatial comparison presents two large maps with complete run names, changed
  parameters, actual stored times, independent Play/Pause controls and optional
  synchronization to the latest other-run time not after the active time.
- Compatible fields use one concentration scale fixed across all snapshots in
  both runs. Exact-time differences use a symmetric right-minus-left scale;
  incompatible times, units, grids or physical domains disable subtraction.
- Extracellular and internalized quantities use separate charts. Absolute and
  relative selected-time differences handle a zero left denominator explicitly.
- Deterministic SVG export uses integrity-checked stored results and embeds
  scientific status, units, exact revisions, engine versions and numerics.
- Legacy run bundles containing only an end field remain readable and are
  labelled as temporally restricted.

The 0.3.0 deterministic single/batch COMBINE/OMEX exchange remains supported.
The browser continues to use the same scientific contracts as the CLI and does
not contain a second biological or numerical implementation.

## Supported product workflow

Install the wheel, build the pinned BioFVM runner, create or import experiments,
execute them through the CLI or loopback workspace, inspect persisted spatial
and temporal results, compare exact compatible snapshots, export scientific
figures and exchange deterministic projects. See the [demonstration guide](../demo.md)
and [research-workspace guide](../research-workspace-ui.md).

Python 3.11 or newer is required. Linux and Windows use the reviewed source-build
route; macOS and prebuilt native engines remain outside this release. On Windows,
use the MSYS2 UCRT64 shell with Git, Make, GCC and
`mingw-w64-ucrt-x86_64-libgomp`; installing GCC without the matching libgomp
package can fail while linking `-lgomp`. See [engine setup](../engine-setup.md).

## Quality boundary

Publication waits for the complete Tests workflow at the exact release commit.
The gate covers unit/regression tests, clean wheel installation, real Chromium
interaction at 1440 × 1000 and 390 × 844, reviewed browser screenshots,
scientific figures, analytical/native BioFVM verification and Windows native
product execution. The publishing workflow independently rebuilds and installs
the wheel, checks package contents and version, and tags the validated commit.

Browser fixtures are synthetic software-verification inputs. They do not
establish biological accuracy. No intermediate spatial field is generated from
an end field, and no missing time is interpolated.

## External scientific gates

- Issue #94 records unresolved aggregation/provenance questions in the external
  mucus workbook. It blocks parameter fitting from that dataset, not generic
  workspace use.
- Issue #83 records the unresolved Smoldyn distribution-license boundary and
  equivalent-experiment requirements. No Smoldyn dependency or code is included.
- Evidence-backed input distributions, formal global sensitivity indices and
  parameter inference need dedicated research designs. Calibration additionally
  requires suitable measured data and an explicit observation model.

Synthetic verification is not experimental evidence. Simulated results are
conditional model predictions; comparisons do not rank biological or therapeutic
benefit. VesicleScope is not a medical device, diagnostic system or clinical
decision tool.

## Installation

Download the wheel from the GitHub v0.4.0 release, then:

```bash
python -m pip install vesicle_scope-0.4.0-py3-none-any.whl
vesiclescope --version
vesiclescope engine status
```

The public repository grants no open-source license by default. Third-party
software retains its own license and citation requirements.
