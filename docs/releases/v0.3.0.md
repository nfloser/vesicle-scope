# VesicleScope 0.3.0

VesicleScope 0.3.0 completes the selected dataset-independent Linux/Windows
continuum research-product scope, including reproducible project exchange.
It is **not biologically validated** as an EV prediction tool.

## New since 0.2.0

- Deterministic COMBINE/OMEX archives for one experiment and matching stored runs.
- Ordered multi-experiment OMEX archives with verified identities, run digests,
  revision and numerical settings.
- CLI archive creation and inspection without solver execution.
- Local browser import/export for individual projects and explicit stored-run batches.
- Collision-safe batch imports with exclusive file creation and rollback after failure.
- Documented Smoldyn comparison semantics and an explicit licensing gate.

The browser uses the same scientific and archive contracts as the CLI. Batch
export is an explicit selection of stored runs; it is not sampling or automatic
parameter inference. Source artifact names become stable archive member names.
Browser batch re-export reconstructs the manifest from authoritative stored runs;
extra custom source-manifest metadata remains in the original archive.

## Supported product workflow

Install the release wheel, build the pinned BioFVM engine, create or import
experiments, execute them through CLI or loopback workspace, inspect spatial and
temporal results, compare compatible fields and stored time series, summarize
explicit ensembles and exchange reproducible archives. See [demo guide](../demo.md).

Linux and Windows use the reviewed source-build route. Python 3.11 or newer is
required. macOS validation and prebuilt native engines remain outside this release.
The optional Matplotlib renderer remains separate from the dependency-free core.

## Quality boundary

Release publication waits for the complete Tests workflow at the exact release
commit. It covers unit/regression tests, clean wheel installation, JavaScript
syntax, analytical/native BioFVM checks, scientific figures and Windows/native
product execution. The publishing job independently rebuilds and installs the
wheel, checks its version and dependencies, and tags the exact validated commit.

## External scientific gates

- Colombo 2025 quantitative biological validation requires raw measurements,
  experimental context and a defensible fluorescence-to-model measurement mapping.
  Publication fit summaries do not replace raw per-sample data.
- Smoldyn integration remains blocked by inconsistent upstream license declarations.
  No Smoldyn dependency or code is included in this release.
- Evidence-backed calibration, sampling distributions, inference and additional
  mechanisms require their own research/data gate.

Synthetic benchmarks are numerical verification inputs, not measured biology.
Simulated results are conditional predictions; ensemble percentile intervals are
not confidence intervals. Run comparisons do not rank biological or therapeutic
benefit. SED-ML compatibility is not claimed for native BioFVM experiments.
VesicleScope is not a medical device, diagnostic system or clinical decision tool.

## Installation

Download the wheel from the GitHub v0.3.0 release, then:

```bash
python -m pip install vesicle_scope-0.3.0-py3-none-any.whl
vesiclescope --version
vesiclescope engine status
```

The public repository grants no open-source license by default. Third-party
software retains its own license and citation requirements.
