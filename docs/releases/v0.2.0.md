# VesicleScope 0.2.0

VesicleScope 0.2.0 completes the current dataset-independent Linux/Windows research-product scope built on the verified BioFVM continuum path.

## Product workflow

Users can now:

- install VesicleScope as a Python package and use the `vesiclescope` CLI;
- build the exact reviewed BioFVM runner through the installed product;
- create, validate, inspect and execute deterministic experiment documents;
- use the loopback-only browser workspace over the same scientific contracts;
- derive new immutable variants from fully synthetic benchmark experiments without silently reusing evidence-backed provenance;
- execute explicit ordered experiment batches;
- persist deterministic run bundles containing exact revision, engine/numerical identity and normalized fields/time series;
- inspect and render stored runs without rerunning BioFVM;
- compare stored runs across their recorded quantity time series and directly compatible final spatial fields without hidden interpolation;
- summarize explicit stored-run ensembles conservatively without inventing biological distributions.

There is no separate demo-only simulation path.

## Scientific and reproducibility boundaries

The release keeps the following distinctions explicit:

- analytical references and numerical verification are not experimental evidence;
- synthetic benchmark parameters are not biological defaults;
- simulated outputs are conditional predictions under a model, parameterization, assumptions and numerical method;
- stored-run ensemble summaries are empirical summaries of supplied runs and are **not confidence intervals**;
- run-to-run deltas, ratios and field differences are numerical comparisons and do **not** rank a condition as biologically better, optimal, therapeutic or physiological.

Direct spatial differences are produced only when concentration units, physical domain, grid, slice thickness and final snapshot time are compatible. VesicleScope does not silently resample incompatible fields.

## Quality and supported product path

The release gate covers:

- clean wheel build and installation;
- package/runtime version consistency and `pip check`;
- Python compilation and unit/regression tests;
- packaged browser asset plus inline JavaScript syntax checking;
- analytical and native BioFVM verification;
- mass-accounting and relevant resolution/timestep checks;
- real loopback HTTP workspace execution through the native runner;
- deterministic artifact persistence/reload;
- reproducible scientific figures;
- Linux and Windows source-build/native execution paths;
- provenance-safe interactive synthetic editing;
- offline batch, ensemble and rich run-comparison workflows.

## Scientific limits that remain

These are explicit research/data gates rather than placeholder implementations:

- the Colombo 2025 external validation target still requires suitable raw/calibration context before stronger biological claims;
- evidence-backed parameter distributions, formal sensitivity analysis and parameter inference require their own research gate; calibration additionally requires suitable measured data;
- continuum-versus-particle comparison remains a future research objective until equivalent experiment semantics and a reviewed alternate-engine decision exist;
- macOS and prebuilt native-engine binaries are not part of this release; Linux and Windows use the reproducible source-build path;
- VesicleScope is not a medical device, diagnostic system or clinical decision tool.

## Installation

Install the release wheel:

```bash
python -m pip install vesicle_scope-0.2.0-py3-none-any.whl
vesiclescope --version
vesiclescope engine status
```

Optional figure support:

```bash
python -m pip install 'vesicle-scope[figures]'
```

The repository intentionally does not grant an open-source license. Third-party dependencies remain subject to their own license and citation requirements.
