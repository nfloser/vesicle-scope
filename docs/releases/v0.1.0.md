# VesicleScope 0.1.0

VesicleScope 0.1.0 is the first complete dataset-independent research-product release of the current continuum transport line.

## What a user can do

A user can install the package, build the exact reviewed BioFVM runner, create or import a validated experiment document, execute it with explicit numerical settings, persist a deterministic run bundle, inspect and compare completed runs, regenerate a stored-run figure without rerunning BioFVM, and use the same workflow through a local browser workspace.

The browser workspace and CLI share the same experiment, execution and run-bundle contracts. There is no demo-only scientific path.

## Verified product path

The release gate verifies:

- package import and runtime version;
- installed CLI;
- packaged browser UI asset;
- packaged canonical native runner source;
- validated experiment export and inspection;
- pinned BioFVM build and execution on Linux;
- pinned BioFVM product path on Windows;
- real loopback HTTP workspace execution;
- deterministic run persistence and reload;
- reproducible scientific figures.

## Scientific interpretation

The current BioFVM path is numerically verified against analytical and controlled synthetic benchmarks.

That is not the same as external biological validation.

Unless explicitly documented otherwise, reviewed examples and factor experiments use `synthetic_benchmark` parameters. VesicleScope output must be interpreted as a prediction conditional on the selected model, parameters, assumptions and numerical method.

## Known release limits

These are deliberate boundaries rather than hidden placeholders:

- the Colombo 2025 validation target still requires suitable raw/calibration context before stronger external biological claims;
- uncertainty propagation and parameter inference need their own research gate and, for calibration, suitable measured data;
- continuum-versus-particle comparison remains future work;
- macOS and prebuilt BioFVM binaries are not part of this first Linux/Windows research release;
- VesicleScope is not a medical device, diagnostic system or clinical decision tool.

## Installation

From a release source tree or wheel:

```bash
python -m pip install vesicle_scope-0.1.0-py3-none-any.whl
vesiclescope --version
vesiclescope engine status
```

Figure support remains optional:

```bash
python -m pip install 'vesicle-scope[figures]==0.1.0'
```

The repository intentionally does not grant an open-source license. Third-party dependencies keep their own license and citation requirements.
