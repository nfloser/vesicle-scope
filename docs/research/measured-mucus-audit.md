- The user explicitly declares noncommercial research use. DRUM's CC BY-NC-ND 3.0 US conditions still travel with the originals; local processing does not grant redistribution rights for adapted measurements. Primary terms: https://creativecommons.org/licenses/by-nc-nd/3.0/us/ and its legal code.
- The primary publication's [Figure 2](https://www.nature.com/articles/s41522-025-00866-9/figures/2) was inspected directly. Its axes label MSD in µm² at lag one second. - The exact source workbook can be audited reproducibly without vendoring data or implementing a spreadsheet parser. openpyxl 3.1.5 provides read-only XLSX access. It is lazy-loaded as an optional data extra. Formula evaluation is disabled and formula cells are rejected.

## Mathematical/statistical scope

For strictly positive supplied values x_i, the independently computed geometric mean is exp(sum(log(x_i))/n). If any supplied value is zero, report zero under the nonnegative-product convention and retain the zero count. No pseudocount or exclusion is applied. This computation is independent of the workbook's stored means and is not presumed to reproduce the authors' full analysis pipeline.

No pooled significance test, fitted model, confidence interval, transport coefficient or biological calibration is produced. Ten donor mucus samples remain the biological grouping level; individual particles are nested measurements.

## Actual-data acceptance and unresolved question

The original hash was verified before parsing and unchanged afterwards. The audit identifies 80 groups and 19,430 particle values with no zeros. Stored sample means are not uniformly reproduced by geometric means across all supplied values. This does not isolate the cause: prior exclusion, aggregation or snapshot differences require additional provenance. The report preserves both summaries and their differences rather than substituting one for the other.

The separate CC0 Dryad v3 package was obtained through its official version endpoint and all 13 source identities were verified on 2026-10-29. A read-only reconciliation on 2026-10-31 found that all 100 stored sample-summary cells agree. The ordered particle sequences have no substantive paired-value mismatch: 19,277 values compare exactly and four differ only by CSV-decimal versus XLSX-binary representation within a recorded relative tolerance of 1e-12. However, DRUM contains 149 additional ordered Sample 1 / *L. crispatus* bEV values (234 versus 85), yielding 19,430 values against Dryad's 19,281. A positional follow-up on 2026-11-01 established that the 85 Dryad values are the exact prefix of the DRUM sequence and that unpaired DRUM values begin at ordinal 86. An aggregation audit on 2026-11-02 then found 59 of 80 stored summaries rounding-consistent with geometric means over all Dryad values and 58 of 80 over all DRUM values. The sole snapshot-specific result is Sample 1 / *L. crispatus* bEV, whose summary matches the Dryad prefix under the explicit decimal-place rule but not the full DRUM sequence. Twenty-one Dryad groups remain unreproduced, so the comparison still does not infer whether differences reflect exclusion, omission or another upstream rule. The article and Figure 2 specify geometric means, whereas the Dryad README describes the stored statistic only as an “average”. A 2026-11-03 negative control found that the unfiltered arithmetic mean reproduces 0 of 80 stored summaries in either verified snapshot under the same decimal-place rule. This rules out one literal interpretation of “average” but does not establish the omitted processing rule. A 2026-11-04 magnitude audit expresses each residual in units of the stored last decimal place: 10 of 21 Dryad mismatches and 10 of 22 DRUM mismatches are above the 0.5-unit acceptance boundary but no more than one unit away. They remain mismatches; one unit is a descriptive boundary, not a relaxed tolerance. A 2026-11-05 inventory audit found explicit removed-outlier companion files for five other assay families but none for CVM and no CVM-specific outlier statement in the README. CVM filtering therefore remains unknown; absence of a companion file does not prove unfiltered values. On 2026-11-06 these existing fitting blockers were made machine-readable in the reconciliation report without changing their scientific interpretation. On 2026-11-08 the primary article's ten-sample design and the deposited sample/species/particle structure were used to select the human CVM sample as the independent biological unit. Individual particle MSD values are nested observations, not independent biological replicates. The machine-readable hierarchy intentionally leaves the fitting summary null; it does not resolve aggregation, filtering, snapshot provenance or the observation model. On 2026-11-09 the observation boundary was made explicit: the source supplies particle-tracking MSD at one second, whereas the current BioFVM path supplies continuum concentration fields. The source does not validate a model observable or a mapping from single-lag MSD to the continuum diffusion coefficient. Both mappings therefore remain null, and normal diffusion is not inferred. Tumor measurements and fluorescence-to-model mapping remain open. These questions prevent parameter fitting, not this narrower measured-data audit.

On 2026-11-10 the official dataset versions endpoint exposed only one public record, version 3 (ID 412881, published 2025-12-09) with file changes. No earlier public snapshot is visible there for comparison, so this route cannot explain the 149 additional DRUM values. It also does not establish whether earlier nonpublic or internal states existed.

On 2026-11-11 each fitting blocker gained a machine-readable evidence requirement. Snapshot and aggregation blockers require source-controlled processing provenance or author clarification; filtering requires an explicit CVM record; mapping requires context-matched trajectory or multi-lag evidence and a validated observation model. These fields specify what is missing without supplying a rule, equation or parameter.
